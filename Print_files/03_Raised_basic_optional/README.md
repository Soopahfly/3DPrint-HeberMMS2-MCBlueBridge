# Raised basic - no light-pipe hole or cable guides

Development revision: v6.

Choose the left or right flap for your installation and use the matching button_long.stl in this folder. The PCB standoff is 5.2 mm above the flat inside face; peg tips reach 6.7 mm. Peg fitting diameter is 2.10 mm. The 5.00 mm BOOTSEL aperture is common to all three published options.

This option has no LED light-pipe hole or cable guides.

Insert the button from inside, then seat the Pico component-side towards the flap. The flange retains the button outwards; the fitted PCB captures it inwards. No separate retaining ring is needed. Check that BOOTSEL presses and releases freely.
